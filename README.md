Moonlit Ramen — a midnight noodle-bar rush game: boil noodles and lift them in the perfect window, pile on the toppings each ticket asks for, and serve before patience runs out, across a 150-second shift with rising levels, tips and combos.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click the ingredient bins (or press 1–8), 8 drops the noodles in the pot, Space serves the finished bowl, P pauses, M mutes.
